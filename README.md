# ITP Quiz System Project

This is a console-based Quiz System project developed in C++ for the Introduction to Programming (ITP) course.

## 🚀 Features
- **Interactive Quiz**: Users can answer questions through the console interface.
- **Scoring System**: Automatically calculates the total score at the end of the quiz.
- **Performance Feedback**: Provides customized feedback based on the user's final score.

## 💻 How to Run
1. Download or clone this repository to your computer.
2. Open the `quiz_project.cpp` file in any C++ compiler (such as Dev-C++ or VS Code).
3. Compile and run the code to start the quiz.
